# Система отслеживания самолетов

Программа для получения информации о самолетах в воздушном пространстве различных стран с использованием открытых API.

## Описание

Приложение собирает данные о самолетах, находящихся в воздушном пространстве выбранной страны, используя:
- **Nominatim OpenStreetMap API** — для получения географических координат страны
- **OpenSky Network API** — для получения информации о самолетах

## Функциональность

- Получение списка самолетов над указанной страной
- Вывод топ N самолетов по высоте полета
- Фильтрация самолетов по стране регистрации
- Фильтрация самолетов по диапазону высот
- Сохранение данных в JSON-файл

## Установка и запуск

### 1. Клонирование репозитория

```
git clone <url-репозитория>
cd airplanes_curse
```


### 2. Установка зависимостей
```
pip install -r requirements.txt
```

### 3. Запуск программы: 
```
python src/main.py
```
